# MIRROR DINER

**Last Order Never Comes**

スマートフォン縦画面向けの、同時進行型オーダー処理ゲームです。
外部API、データベース、APIキー、環境変数、外部音源は使用しません。
ゲームの進行状況と厨房設備は、プレイヤーのブラウザ内に保存されます。

## 収録内容

- EASY／NORMAL／HARD／EXTRAの4難易度
- 90秒のスコアアタック（スタッフ用品「サービス残業」で最大120秒）
- 最大3件のランダム注文
- グリドル、フライヤー、ドリンク台の同時調理
- 完成、焦げ、回収、ゴミ箱への廃棄
- バーガーやHARD専用料理の組み立て
- HARD常設のオニオンフライ／デンバーオムレツ
- 勤務ごとに変わるTODAY'S SPECIAL
- メイプルチキンパンケーキ／オニオンリングバーガー／ドーナツサンデー
- 初登場レシピの案内と、営業中に開けるレシピ帳
- EXTRAの選択式ミッション4種
- スタッフ用品（タイムカード／スマイル／サービス残業）
- 伝票への登録、取り戻し、正誤判定
- コンボ、速度ボーナス、営業成績
- チップを使った厨房設備とスタッフ用品の購入
- ブラウザ内へのチップ、設備、用品、難易度、ミッション、レシピ既読状態の保存
- 外部音源を使わない効果音
- スマートフォン縦画面とPC操作への対応

## 必要環境

- Node.js 20以降
- npm

## ローカルで遊ぶ

ZIPを展開し、フォルダ内で次を実行します。

```bash
npm install
npm run dev
```

ターミナルに表示されたURLをブラウザで開いてください。

同じネットワーク内のスマートフォンから確認する場合：

```bash
npm run dev -- --host 0.0.0.0
```

## 本番ビルド

```bash
npm install
npm run build
```

公開用ファイルは `dist/` に生成されます。

## GitHubへ保存する

1. GitHubで空のリポジトリを作成します。
2. このフォルダの中身をすべてリポジトリへ追加します。
3. `main` ブランチへコミットしてpushします。

主なファイル：

- `index.html` — HTMLの入口
- `src/main.jsx` — Reactの起動処理
- `src/components/MirrorDinerGame.tsx` — ゲーム画面と進行処理
- `src/gameData.ts` — メニュー、難易度、調理時間、得点、客、設備
- `src/styles.css` — UI、ピクセルアート、レスポンシブ表示
- `public/favicon.svg` — ブラウザアイコン
- `vite.config.js` — Viteのビルド設定
- `vercel.json` — Vercelの公開設定

## Vercelへ公開する

1. Vercelにログインし、「Add New Project」を選びます。
2. GitHubへ保存したMIRROR DINERのリポジトリをImportします。
3. Framework Presetが `Vite` になっていることを確認します。
4. 環境変数は追加せず、そのままDeployします。

以後は `main` ブランチへpushするたびに、Vercelが自動で再公開します。

## 操作

1. 難易度を選び、「営業をはじめる」を押します。
2. 調理設備のボタンで調理を始めます。
3. 完成した設備を押し、料理をストックへ回収します。
4. 材料を回収したら、仕上げ台でバーガーやスペシャル料理を組み立てます。
5. 注文票を選び、ストックの商品を選んで伝票へ登録します。
6. 伝票内の登録済み商品を押すと、ストックへ戻せます。
7. 全商品が揃ったら「提供」を押します。
8. 不要な商品はストックで選び、ゴミ箱へ廃棄します。

営業終了後に獲得したチップで設備を増設し、スタッフ用品を購入できます。

## データの保存とリセット

チップ、設備レベル、スタッフ用品、選択した難易度・ミッション、確認済みレシピはブラウザの `localStorage` に保存されます。
別のブラウザや端末には引き継がれません。進行をリセットしたい場合は、ブラウザのサイトデータを削除してください。
